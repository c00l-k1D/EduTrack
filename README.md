# EduTrack

EduTrack - это настольное приложение для школьного реестра учащихся. Программа предназначена для:

- поиска учащихся по диапазону возраста в Excel, CSV и TXT-файлах;
- автоматического распознавания ФИО, даты рождения и класса;
- сохранения записей в локальную базу данных SQLite;
- массового зачисления, перевода и выбытия;
- экспорта итогового CSV-отчёта;
- ведения журнала действий и резервных копий данных;
- проверки обновлений через GitHub и настройки репозитория обновлений.

Приложение используется в школе, филиале или учебном центре для формирования списка детей по поступлению и актуальному контингенту.

---

## 1. Что умеет программа

### Основной сценарий

Пользователь указывает папку или файл с данными о детях. Программа:

1. читает таблицы из CSV, Excel и TXT;
2. ищет строки, в которых есть ФИО и дата рождения;
3. отбирает записи, у которых возраст соответствует заданному диапазону;
4. сохраняет результат в реестр базы данных;
5. формирует CSV-отчёт для дальнейшего использования.

### Поддерживаемые форматы данных

- Excel: .xlsx, .xls, .xlsm
- CSV: .csv
- TXT/TSV: .txt, .tsv

### Поддерживаемые типы колонок

Программа пытается распознать поля по названию столбца, например:

- ФИО: ФИО, fio, full_name, student, name
- Дата рождения: Дата рождения, birthday, dob
- Класс: Класс, class, grade

Если название колонок отличается, программа всё равно пытается сопоставить их по смыслу.

### Массовые операции

После поиска по данным доступны операции:

- массовое зачисление;
- массовый перевод в другой класс;
- массовое выбытие.

Все операции требуют подтверждения и фиксируются в журнале действий.

### Журнал и база данных

Данные сохраняются в SQLite в файл edutrack.db. В базе есть:

- таблица учащихся;
- история изменений;
- журнал аудита;
- учётные записи сотрудников;
- настройки приложения.

Структура базы позволяет вести контроль данных и восстанавливать состояние после сбоя.

## 2. Требования

- Python 3.11+

- Библиотеки:
  - pillow

2. Создайте виртуальное окружение:


## 5. Форматы входных данных

### Пример CSV

```csv
ФИО;Дата рождения;Класс
Иванов Иван Иванович;12.05.2012;8А
Петрова Мария Сергеевна;04.09.2011;8Б
```

### Пример TXT

```txt
Иванов Иван Иванович    12.05.2012
Петрова Мария Сергеевна  04.09.2011
```

### Пример Excel

Столбцы могут называться так:

- full_name
- birthday
- class

или на русском:

- ФИО
- Дата рождения
- Класс

Программа сама понимает, что это за поля, даже если названия различаются.

---

## 6. Как работает поиск

Система последовательно делает следующее:

1. читает файлы в папке или выбранный файл;
2. извлекает строки в каждой таблице;
3. ищет среди колонок поля, похожие на ФИО и дату рождения;
4. проверяет, что дата корректна;
5. вычисляет возраст относительно текущей даты;
6. оставляет только записи, чьё значение попадает в диапазон возраста;
7. сохраняет найденные записи в базе и возвращает результат на экран.

По умолчанию используется диапазон:

- от 14 лет;
- до 15 лет.

Этот диапазон можно изменить в интерфейсе.

---

## 7. Работа с базой данных

Файл базы данных создаётся автоматически при первом запуске:

- edutrack.db

### Основные таблицы

- students - карточки учащихся
- student_history - история изменений и переводов
- audit_log - журнал действий
- users - аккаунты сотрудников
- settings - настройки приложения

### Бизнес-правила

- ФИО + дата рождения считаются уникальной комбинацией;
- дата рождения не может быть пустой или будущей;
- при массовых операциях всё выполняется в транзакции;
- при ошибках данные откатываются, чтобы избежать частичного обновления.

---

## 8. Массовые операции с учениками

### 1. Зачисление

Используется, когда в исходном списке есть дети, которые поступают в школу или группу.

- выбираются строки в таблице;
- подтверждается операция;
- запись в реестре обновляется;
- в истории сохраняется причина операции.

### 2. Перевод

Команда переводит выбранных учащихся в другой класс.

Необходимо указать:

- новый класс;
- причину операции;
- подтверждение пользователя.

### 3. Выбытие

Используется при завершении обучения, отчислении или переводе в другое учреждение.

- статус ученика меняется на "Выбыл";
- класс очищается;
- запись сохраняется в истории, чтобы не терять данные.

## 9. Авторизация и безопасность

Приложение создаёт учётную запись по умолчанию:

- логин: admin
- пароль: admin123

Это нужно для первой настройки. После запуска рекомендуется:

- сменить пароль администратора;
- ограничить доступ к папке с базой данных,
- не хранить критические данные в открытом виде;
- регулярно делать резервные копии.

Данные учётных записей хранятся в SQLite, а пароль шифруется через хэширование.

## 10. Резервные копии и восстановление

Программа умеет создавать резервные копии базы данных через функции:

- backup_database()
- restore_database()

### Пример

```python
backup_database("backups/edutrack_backup.db")
restore_database("backups/edutrack_backup.db")
```

### Шифрование резервной копии

Поддерживается режим шифрования:

```python
backup_database("backups/edutrack_backup.db", encrypt=True, password="my_secret")
```

Для шифрования используется простой XOR-подобный алгоритм на основе SHA-256. Это базовая защита, но для реального продакшена стоит использовать более сильный механизм хранения секретов.

## 11. Обновление

В приложении можно настроить репозиторий обновлений на GitHub, например:

```text
https://github.com/c00l-k1D/EduTrack
```

После этого программа проверяет наличие новых релизов и предлагает обновление.

Если проект клонирован через Git, обновление выполняется через:

```bash
git fetch --tags
git pull --ff-only
```

Если проект не является Git-репозиторием, приложение открывает страницу релиза в браузере.

## 12. Командная строка

Программа поддерживает запуск в CLI-режиме без GUI.

### Примеры

Поиск по папке:

```bash
python main.py C:\data\students --min-age 14 --max-age 15
```

Поиск по конкретному файлу и экспорт отчёта:

```bash
python main.py C:\data\students.xlsx --output C:\reports\students.csv
```

Или явный параметр папки:

```bash
python main.py --folder C:\data\students --min-age 14 --max-age 15 --output report.csv
```

## 15. Возможные проблемы и решения

### 1. Файл не читается

Проверьте:

- расширение файла;
- кодировку;
- разделители столбцов;
- наличие заголовков в первой строке.

### 2. Не найдено учеников

Проверьте:

- диапазон возраста;
- корректность даты рождения;
- правильные названия колонок;
- формат даты (дд.мм.гггг, дд-мм-гггг и т. п.).

### 3. Не открывается обновление

Проверьте:

- доступ к интернету;
- корректный URL GitHub;
- установку Git на компьютере.

### 4. Приложение не запускается

Проверьте установку зависимостей:

```bash
pip install pillow openpyxl
```

- обработки заявок на поступление;
- ведения списка учащихся;
- контроля возраста и классов;
