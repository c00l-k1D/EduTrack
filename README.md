# EduTrack

EduTrack — приложение для учёта и мониторинга учеников в школьном реестре. Проект включает:

- поиск и импорт данных из Excel/CSV/TXT
- проверку возраста, даты рождения и дублей
- хранение данных в SQLite
- журналирование изменений и резервные копии
- базовую авторизацию сотрудников
- массовые операции зачисления, перевода и выбытия

## Установка и запуск

1. Установить Python 3.11+.
2. Создать виртуальное окружение:
   ```bash
   python -m venv .venv
   .venv\Scripts\Activate.ps1
   ```
3. Установить зависимости:
   ```bash
   pip install pillow openpyxl pyinstaller
   ```
4. Запустить приложение:
   ```bash
   python main.py
   ```

## Проверка на чистой Windows 11

- запустить приложение на чистой машине без лишних библиотек
- проверить, что работает запуск из папки без Python
- подтвердить корректную работу базы `edutrack.db`
- проверить импорт CSV/Excel/TXT и экспорт CSV
- убедиться, что бэкап и восстановление работают

## Сборка через PyInstaller

```bash
pyinstaller --onefile --windowed --icon icon.ico --name EduTrack main.py
```

Готовый исполняемый файл будет размещён в папке `dist`.

## Резервное копирование и восстановление

Используются функции:

- `backup_database()`
- `restore_database()`
- `backup_database(..., encrypt=True)`

При включённом шифровании используется простой симметричный потоковый XOR с ключом на основе SHA-256. Для продакшн-среды рекомендуется менять ключ через `write_setting("backup_password", "...")` и хранить его в защищённом месте.

## Безопасность

По умолчанию создаётся сотрудник:

- логин: `admin`
- пароль: `admin123`

После запуска желательно сменить пароль и ограничить доступ к папке с базой данных, бэкапами и журналами.

## Проверка после перезапуска

После каждого перезапуска выполняется `ensure_database()`, которая проверяет таблицы, восстановление учётных записей и возможность работы с SQLite.
